Escenario: Carga de pedidos a bodegas

Dado que se muestra la pantalla para la carga de pedidos a bodegas  
Y la aplicación está conectada a la base de datos  

Cuando se selecciona el apartado "Bodegas de origen" y se selecciona "Bodega 2"  
Y se completa el campo "RUT" con "123456789"  
Y se selecciona el dropdown "Destino" y se selecciona la opción "Ubicación 1"  
Y se completa el campo "Número de pedido" con "987"  
Y se hace clic en el botón "Grabar pedidos"  

Entonces el pedido se graba en la base de datos  
Y el proceso de carga de pedidos queda completado
